# The Access Audit — published site

Static marketing site for **The Access Audit**, an independent WCAG 2.1 AA
website accessibility audit service (Aaron Siebold).

Served by GitHub Pages. No build step, no dependencies, no JavaScript
anywhere on the site — a Content-Security-Policy of `default-src 'none'`
is declared on every page.

`sample-report.html` is a real, unedited report produced by the audit
pipeline, run against Deque's intentionally broken demo site.
